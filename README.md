# Telegram Voice Library Bot

## Что умеет
- Все пользователи могут вызывать голосовые командами вида `/svetlana_vecher`.
- Все пользователи могут смотреть `/voices` и вызывать `/randomvoice`.
- Только владелец с Telegram ID `417850992` может добавлять, удалять записи и смотреть `/stats`.
- Добавление и удаление выполняются только в личке с ботом.
- Голосовые сохраняются по Telegram `file_id` в SQLite и отправляются как voice message.

## Локальный запуск
1. Установи Python 3.11 или 3.12.
2. Выполни `pip install -r requirements.txt`.
3. Скопируй `.env.example` в `.env` и впиши токен от BotFather.
4. Запусти `python main.py`.

## Команды администратора (только в личке)
- `/addvoice имя_команды` — начать добавление; затем отправить боту именно голосовое сообщение.
- `/cancel` — отменить ожидание голосового.
- `/deletevoice имя_команды` — удалить запись.
- `/stats` — статистика.

## Команды для всех
- `/voices` — список.
- `/randomvoice` — случайная запись.
- `/имя_команды` — отправить выбранное голосовое.

Имя команды: латинские буквы, цифры и `_`, от 1 до 32 символов, первый символ — буква. Например `svetlana_vecher`.

## Развёртывание на Bothost
1. Загрузи содержимое проекта в свой GitHub-репозиторий. Не загружай `.env` и токен.
2. В Bothost создай Python-приложение/worker из GitHub-репозитория.
3. Укажи команду запуска `python main.py` (или используй Procfile `worker: python main.py`).
4. В настройках приложения добавь переменные:
   - `BOT_TOKEN` — токен от BotFather
   - `OWNER_ID` — `417850992`
   - `DATABASE_PATH` — абсолютный путь к файлу базы в постоянном хранилище, например `/app/data/voices.db`, если такой путь указан в настройках/документации твоего проекта Bothost.
   - `LOG_LEVEL` — `INFO`
5. Подключи persistent storage/постоянный диск к приложению и убедись, что папка для `DATABASE_PATH` находится именно на нём. Иначе база может пропасть при пересоздании контейнера.
6. Установи Python 3.12 (или 3.11), зависимости из `requirements.txt`, запусти приложение и проверь логи: должна появиться строка `Bot started as @...`.

Названия пунктов панели Bothost могут отличаться. Важно, чтобы процесс работал как постоянно запущенный worker, а SQLite-файл лежал на постоянном диске.

## Добавление бота в группу
1. Добавь бота в Telegram-группу.
2. Если хочешь вызывать команды коротко, например `/svetlana_vecher`, без `@имя_бота`, открой BotFather → `/setprivacy` → выбери бота → `Disable`.
3. Если Privacy Mode оставить включённым, в группе используй адресованный формат `/svetlana_vecher@ИмяБота`.
4. Для отправки голосовых достаточно права отправки сообщений; администратором группы делать бота не требуется.

## Важно
- Токен хранится только в переменных окружения Bothost, не публикуй его в GitHub и не отправляй никому.
- Не запускай одновременно две копии этого polling-бота с одним токеном.
- Для сохранности записей делай резервные копии `voices.db`.
